# Triadz

Next.js 16 website for Triadz, deployed as a Node.js application on GoDaddy Node.js Hosting.

## Runtime

- Node.js 22
- Next.js App Router
- Production command: `npm start`
- Build command: `npm run build`

This application requires the Next.js Node.js server. Do not deploy it as a static export or GitHub Pages site: the contact Route Handler and Server Actions require a server runtime.

## Local development

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Fill in the Gmail app password in `.env.local` before testing email delivery. Never commit `.env.local` or any credential.

## GoDaddy Node.js Hosting

1. Create a Node.js app in GoDaddy Node.js Hosting and connect it to the `Triadz-Hub/Triadz` repository, or upload the source ZIP generated by the GitHub Actions workflow.
2. Use Node.js 22. The app must run `npm run build` during deployment and `npm start` at runtime.
3. Attach the GoDaddy Web Hosting subscription to the app before publishing.
4. Add the following environment variables to both the Preview and Publish variants in GoDaddy:
   - `SMTP_HOST=smtp.gmail.com`
   - `SMTP_PORT=587`
   - `SMTP_SECURE=false`
   - `SMTP_USER=triadzsolutions@gmail.com`
   - `SMTP_PASSWORD=<Google App Password>`
   - `SMTP_FROM=Triadz Solutions <triadzsolutions@gmail.com>`
   - `CONTACT_RECEIVER_EMAIL=sales@triadz.in`
5. Create GitHub Actions repository secrets `GODADDY_PAT` and `GODADDY_APP_ID` to enable automatic source import and publish from the workflow. The GoDaddy Personal Access Token needs `hosting.source:write`, `hosting.source:read`, `hosting.application:read`, and `hosting.deployment:execute` scopes for this existing-app import/publish workflow.
6. The GoDaddy workflow runs a production build on every push to `main`. When the two GoDaddy secrets are set, it uploads the app source and publishes the connected GoDaddy app.

GoDaddy's Node.js Hosting requires an eligible Web Hosting plan attached to the app before it can be published. The platform builds the uploaded source, so the deployment ZIP must include the application source and `package.json` at its root, but must not include `node_modules` or secret environment files.

## Gmail app password

Enable 2-Step Verification on the Google account, then create an App Password for this app (when the Google account offers that option). Store it in GoDaddy's environment secrets as `SMTP_PASSWORD`. Do not use your normal Gmail password.

## Domains

Canonical hostname: **https://triadz.in**

Attach both `triadz.in` and `www.triadz.in` to the same GoDaddy app. The root-level `proxy.ts` redirects requests from `www.triadz.in` to `https://triadz.in` with a permanent 308 redirect while preserving the path and query string. Configure the DNS records GoDaddy displays for each attached hostname; do not use a GitHub Pages CNAME record.

## Contact API

The contact form submits `multipart/form-data` to `POST /api/contact`. The API returns:
- `200` when the notification email is delivered.
- `400` or `415` for malformed requests.
- `413` when an attachment exceeds the configured 10 MB limit.
- `422` for form validation failures.
- `502` when Gmail rejects authentication or email delivery fails.
- `503` when required SMTP configuration is missing or invalid.

SMTP diagnostics are written to server logs. Detailed provider errors and credentials are not returned to visitors.
